# JavaScript Roadmap

This repository documents my studies following the
[JavaScript Roadmap](https://roadmap.sh/javascript) from [roadmap.sh](https://roadmap.sh/).

The goal is to build a solid understanding of JavaScript,
from its fundamentals to more advanced concepts, while keeping
the learning process practical through notes, examples and exercises.

## 📚 Roadmap

The repository follows the same structure and progression as the
official roadmap.

- [Variables](./variables)
- [Data Types](./data-types)
- [Type Casting](./type-casting)
- [Data Structures](./data-structures)
- ...
